# Jaime Díaz-Trechuelo — portfolio

Static portfolio website prepared for GitHub Pages. No build step is required.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload everything in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.

GitHub will provide the public URL after the first deployment finishes.

## Edit the site

- Page content: `index.html`, `research.html`, `background.html`, `notes.html`, and `cv.html`
- Colours and layout: `styles.css`
- Portrait: `assets/jaime-diaz-trechuelo-portrait.png`
- Downloadable CV: `assets/jaime-diaz-trechuelo-cv.pdf`
- Accent colour: change `--accent` near the top of `styles.css`

All internal links are relative, so the website works both at a GitHub Pages project URL and with a custom domain.
