# Lecture-note files

Place reviewed PDF notes in this folder and add links to them in `notes.html`.
Use lowercase, descriptive filenames, for example:

- `stochastic-processes.pdf`
- `markov-processes.pdf`
- `numerical-analysis.pdf`
- `multivariate-statistics.pdf`

Do not publish raw drafts containing copyrighted course material or personal annotations you do not want public.
